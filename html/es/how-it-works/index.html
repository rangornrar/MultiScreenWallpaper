Cómo funciona el workflow renovado de WallCraft

La interfaz 2026.3.14 está construida alrededor de un ciclo más simple: importar, colocar, escalar, reordenar, previsualizar y aplicar.

Cinco pasos desde las imágenes al escritorio

El workflow actual es más fácil de entender y controlar.

01

Importar imágenes

Cargar una o varias fotos en la biblioteca del proyecto.

02

Construir la composición

Colocar las imágenes dentro del escritorio virtual y elegir un layout.

03

Escalar sin distorsión

Usar el modo dedicado para cambiar el tamaño respetando la proporción.

04

Ajustar el orden visual

Enviar una imagen atras o delante cuando hay superposiciones.

05

Previsualizar y aplicar

Validar la vista multi-monitor y luego exportar o aplicar en Windows.
