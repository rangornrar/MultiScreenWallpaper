WallCraft Pro FAQ

Common questions and detailed answers.

Does WallCraft Pro crop images?

Not by default. Fit mode keeps every image whole, so empty space can remain. The optional Fill mode covers the screens and crops each photo around detected faces, never distorting it.

Can one image line up across screens of different sizes?

Yes. Turn on Real screen size in the Screens menu: each screen is placed by its physical size and the gap between panels, so a horizon stays straight across a 27-inch and a 24-inch display.

Does it work with different monitor sizes?

Yes. Mixed resolutions, different heights, and uneven desk layouts are the core use case.

Can I export and split by screen?

Yes. The app can export a large composition and split the result into per-monitor images mapped to your physical setup.

Can it apply wallpapers directly on Windows?

Yes. The project uses the native Windows desktop wallpaper API when available, with a span fallback when needed.

Is it open source?

Yes. The source code is public on GitHub, which helps with trust, inspection, and community contributions.

Is there a versioned GitHub release already?

Yes. The current packaged release is v2026.11.8 on GitHub Releases, with a Windows executable and its SHA-256 checksum.

Does it keep my wallpaper when I dock or undock my laptop?

Yes. WallCraft remembers one wallpaper per screen setup and reapplies it when screens change or when Windows restores a theme. It can stay in the notification area, start with Windows and rotate images from a folder.
