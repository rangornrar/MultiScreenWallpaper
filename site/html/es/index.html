Novedades de 2026.11.13

Disenar fondos para escritorios multi-monitor reales

La versión 2026.11.13 alinea las imágenes según el tamaño real de sus pantallas, puede rellenar cada pantalla recortando alrededor de las caras y mantiene el fondo cuando cambian las pantallas.

  • Un horizonte sigue recto entre un monitor de 27 y otro de 24 pulgadas, con el espacio entre paneles.
  • Ajustar (imágenes enteras) o Rellenar (recorte alrededor de las caras), y 4 variantes estables para elegir.
  • WallCraft se queda en el área de notificación para volver a aplicar o rotar el fondo.

Primeros pasos

De la carpeta de fotos al escritorio en cinco pasos.

01

Añadir imágenes

Botón «Añadir imágenes» o arrastrar y soltar. Las fotos del teléfono se enderezan.

02

Elegir una disposición

Seis disposiciones, incluida la optimización máxima. Variantes… propone otras cuatro.

03

Ajustar o Rellenar

Ajustar conserva cada imagen entera; Rellenar cubre las pantallas recortando alrededor de las caras.

04

Retocar con el ratón

Mover, Escalar, Recortar, capas, rotación y retoques. Ctrl+Z deshace.

05

Aplicar

«Aplicar como fondo» corta la composición y la aplica pantalla por pantalla.
