FAQ WallCraft Pro

Preguntas y respuestas detalladas.

¿WallCraft Pro recorta las imágenes?

No por defecto. El modo Ajustar mantiene cada imagen entera, así que puede quedar espacio vacío. El modo Rellenar, opcional, cubre las pantallas y recorta cada foto alrededor de las caras detectadas, sin deformarla nunca.

¿Una imagen puede quedar alineada entre pantallas de distinto tamaño?

Sí. Active el tamaño real en el menú Pantallas: cada pantalla se coloca según su tamaño físico y el espacio entre paneles, así un horizonte sigue recto entre un monitor de 27 y otro de 24 pulgadas.

¿Funciona con monitores de distintos tamaños?

Sí. Resoluciones mixtas, alturas distintas y disposiciones irregulares son justo el caso de uso principal.

¿Puedo exportar y dividir por pantalla?

Sí. La aplicación puede exportar una composición grande y dividir el resultado en imágenes por monitor.

¿Puede aplicar el fondo directamente en Windows?

Sí. El proyecto usa la API nativa de fondos de Windows cuando está disponible, con modo panorámico como respaldo.

¿Es open source?

Sí. El código fuente es público en GitHub, lo que mejora la confianza, la revisión y las contribuciones.

¿Ya existe una release versionada en GitHub?

Sí. La versión empaquetada actual es la v2026.11.13 en GitHub Releases, con un ejecutable para Windows y su huella SHA-256.

¿Se mantiene el fondo al conectar o desconectar el portátil?

Sí. WallCraft guarda un fondo por configuración de pantallas y lo vuelve a aplicar cuando cambian las pantallas o cuando Windows restaura un tema. Puede quedarse en el área de notificación, iniciarse con Windows y rotar imágenes de una carpeta.
