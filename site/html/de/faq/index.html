FAQ WallCraft Pro

Detaillierte Fragen und Antworten.

Schneidet WallCraft Pro Bilder zu?

Standardmäßig nicht. Der Modus Einpassen zeigt jedes Bild vollständig, daher kann Leerraum bleiben. Der optionale Modus Füllen bedeckt die Bildschirme und schneidet jedes Foto um erkannte Gesichter zu, ohne es je zu verzerren.

Bleibt ein Bild über unterschiedlich große Bildschirme ausgerichtet?

Ja. Aktivieren Sie die reale Größe im Menü Bildschirme: Jeder Bildschirm wird nach seiner physischen Größe und dem Abstand zwischen den Panels platziert, sodass ein Horizont zwischen einem 27- und einem 24-Zoll-Monitor gerade bleibt.

Funktioniert es mit unterschiedlich großen Monitoren?

Ja. Gemischte Auflösungen, verschiedene Höhen und ungleichmäßige Setups sind genau der Kern-Anwendungsfall.

Kann ich nach Monitor exportieren und aufteilen?

Ja. Die App kann eine große Komposition exportieren und das Ergebnis passend zu deinem physischen Setup in Einzelbilder pro Monitor teilen.

Kann die App Wallpaper direkt unter Windows anwenden?

Ja. Das Projekt nutzt die native Windows-Desktop-Wallpaper-API, wenn sie verfügbar ist, und wechselt sonst auf einen Span-Fallback.

Ist das Projekt Open Source?

Ja. Der Quellcode ist auf GitHub öffentlich, was Vertrauen, Prüfbarkeit und Beiträge erleichtert.

Gibt es schon eine versionierte GitHub-Release?

Ja. Die aktuelle paketierte Version ist v2026.11.13 in GitHub Releases, mit einer Windows-EXE und ihrer SHA-256-Prüfsumme.

Bleibt das Hintergrundbild erhalten, wenn ich den Laptop an- oder abdocke?

Ja. WallCraft merkt sich ein Hintergrundbild pro Bildschirmkonfiguration und wendet es erneut an, wenn sich die Bildschirme ändern oder Windows ein Design wiederherstellt. Es kann im Infobereich bleiben, mit Windows starten und Bilder aus einem Ordner wechseln.
